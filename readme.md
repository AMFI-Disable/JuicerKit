# JuicerKit

JuicerKit is a product-neutral MIT Swift package for shared Juicer bundle applications.

It currently provides safe command execution, path validation, app-removal preview models, leftover scanning, and recoverable Trash execution. It contains no SwiftUI views and has no dependency on the Juicer application.

JuicerKit is maintained independently at `https://github.com/amfi-disable/JuicerKit` and contains no BrewStore-specific UI or dependency on the Juicer application.
